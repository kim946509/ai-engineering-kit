# Profiles

프로필은 generic core 위에 적용하는 선택적 환경 확장입니다. 공통 상태 모델이나 작업 템플릿을 복제하지 않고 플랫폼별 노드, 검증 명령, 도구와 승인 경계만 추가합니다.

예정된 첫 프로필은 iOS 앱 개발입니다. SwiftUI 구조, Xcode build/test, Simulator, 접근성, 성능, 메모리, App Store 릴리스 루프를 다루되 실제 도구가 연결되기 전에는 `supported`로 표시하지 않습니다.

프로필은 다음 정보를 가져야 합니다.

- 활성화 조건
- 필요한 AI 도구 또는 플러그인
- 추가하거나 대체할 그래프 노드
- 실제 검증 명령과 증거 형식
- 사람 승인이 필요한 외부 작업
- 제거 또는 롤백 방법
